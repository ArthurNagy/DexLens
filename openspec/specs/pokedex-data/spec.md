# pokedex-data Specification

## Purpose
Provide the complete bundled Pokédex data set and a search index that work offline from the first launch.

## Requirements

### Requirement: Bundled species coverage
The app SHALL bundle all 1,025 species with their Pokédex number, names in every available language, genus, types,
height, weight, base stats, abilities including hidden ones, evolution line with triggers, egg groups, gender ratio
and forms. It SHALL also bundle each variety's level-up learnset per game with the moves' names, types and power as of
that game, and the wild locations where each variety is found per game version, with the method and level range.

#### Scenario: All species present offline
- **WHEN** the app opens its database for the first time with no network
- **THEN** 1,025 species are available and each has at least one type, six base stats and one ability

#### Scenario: Names in every language
- **WHEN** a species is read
- **THEN** its name is available in each of the 12 languages PokeAPI provides species names for

#### Scenario: Tricky names preserved
- **WHEN** the names of Nidoran♀, Mr. Mime, Farfetch'd, Flabébé, Type: Null, Ho-Oh, Porygon-Z and Pecharunt are read
- **THEN** each matches its official spelling, including symbols, accents and punctuation

#### Scenario: Learnsets bundled
- **WHEN** the bundled data is checked
- **THEN** Bulbasaur learns Vine Whip by level up in every game from Red / Blue to Scarlet / Violet

#### Scenario: Move as of the game
- **WHEN** a move's type changed between games, such as Bite becoming Dark in Gold / Silver
- **THEN** the learnset for an earlier game shows the earlier type

#### Scenario: Locations bundled
- **WHEN** the bundled data is checked
- **THEN** Pikachu is found in Viridian Forest in Red and in Blue

### Requirement: Ability descriptions use PokeAPI wording
The app SHALL describe abilities using PokeAPI's own ability prose, and SHALL NOT bundle in-game ability text.

#### Scenario: Ability has PokeAPI prose
- **WHEN** a main-series ability is read
- **THEN** its short effect and effect text come from PokeAPI's ability prose

### Requirement: No bundled game content
The repository and the APK SHALL NOT contain official art, sprites or word-for-word game flavor text.

#### Scenario: Database has no flavor text
- **WHEN** the bundled database is inspected
- **THEN** it has no flavor text table and no image data

### Requirement: Evolution triggers
The app SHALL record how each species evolves, including the trigger and its conditions.

#### Scenario: Level evolution
- **WHEN** the evolution of Ivysaur is read
- **THEN** it evolves from Bulbasaur at level 16

#### Scenario: Item evolution
- **WHEN** the evolution of Vaporeon is read
- **THEN** it evolves from Eevee using a Water Stone

### Requirement: Type chart data
The app SHALL bundle the complete type chart so that matchups can be computed on the device.

#### Scenario: Chart is complete
- **WHEN** the type chart is read
- **THEN** it has a damage factor for all 324 attacking and defending pairs of the 18 types

### Requirement: Full-text name index
The app SHALL index the names of all species in every language for prefix search that ignores case, accents and
punctuation.

#### Scenario: Prefix without accents finds accented name
- **WHEN** the index is queried with the prefix "flabebe"
- **THEN** Flabébé is returned

#### Scenario: Punctuation is ignored
- **WHEN** the index is queried with "mr mime", "farfetchd", "type null", "hooh" or "porygonz"
- **THEN** the matching species is returned

#### Scenario: Other-language name found
- **WHEN** the index is queried with the French name "Bulbizarre" or the Japanese name "フシギダネ"
- **THEN** Bulbasaur is returned

### Requirement: Reproducible database build
The bundled database SHALL be generated by a script from a pinned PokeAPI commit and Room's exported schema, and SHALL
open with Room's schema validation passing.

#### Scenario: Prebuilt file passes validation
- **WHEN** Room opens the bundled database on a device
- **THEN** the schema validation and identity check pass without a migration or data loss
